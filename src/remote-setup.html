Das Touchpad geht sofort. Für die Gyro-Steuerung (Handy schwenken) einmalig das Zertifikat einrichten — danach landest du mit dieser Adresse direkt auf der Fernbedienung.

Warte auf Zertifikat…
Bitte diese Seite in Safari öffnen — andere Browser können auf dem iPhone keine Zertifikate installieren.
  1. Zertifikat laden
    Unten tippen, dann bei der Frage „Konfigurationsprofil laden?“ auf Erlauben. Zertifikat laden
  2. Profil installieren
    Einstellungen-App öffnen → ganz oben „Profil geladen“ antippen → Installieren (oben rechts) → Code eingeben → nochmal Installieren.
    Falls oben nichts steht: Allgemein → VPN und Geräteverwaltung → TV Launcher Fernbedienung
  3. Zertifikat vertrauen
    Einstellungen → Allgemein → Info → ganz nach unten → Zertifikatsvertrauenseinstellungen → TV Launcher Fernbedienung einschalten → Fortfahren.
  4. Zurück zu Safari
    Diese Seite erkennt es von selbst und springt zur Fernbedienung. Fernbedienung öffnen
Android? Zertifikat laden (Schritt 1), dann Einstellungen → Sicherheit → Verschlüsselung & Anmeldedaten → Zertifikat installieren → CA-Zertifikat → die geladene Datei wählen. Danach in Chrome zurück auf diese Seite.
